## 2. The pipeline, in one line

`edit website/** → push → Netlify (~30–60s) → the WP page's shortcode re-fetches → live`

**The plugin is the exception.** `website/wp-mu-plugin/vc-clients-embed.php` is a *manual
upload* to `/wp-content/mu-plugins/`. Pushing the repo does **not** update it. This has already
cost one round of confusion — if shortcodes render as literal text on a page, the plugin is
older than the shortcodes, and that's a human upload step, not something you can fix.

## 3. Rules you must not break

- **Consume the shared engine.** `brgw.css` + `brgw.js` self-init on every `.brgw` root. Never
  add a second reveal init, slider or doodle system.
- **Fragment contract** (SPEC-001 §4): one root element, **no `.brgw` wrapper**, all CSS scoped
  under `.brgw-sec--<id>`, root carries `reveal`, no per-section JS.
- **Cross-section bleed rule** (Conti's ruling): an element crossing a seam **lives in the LOWER
  section and bleeds UPWARD**. Later shells paint on top, so upward bleed shows and downward
  bleed gets covered. Every seam badge on the site follows this.
- **Clear shared changes through Conti** — `brgw.css`, `brgw.js`, the plugin, `pages.json`,
  `sections.json`, or a new page/section. Log a `NEED:` in `notes/finesser.md` and wait for a
  `DECISION:`. Pure polish inside one fragment just proceeds, logged `DONE:`.
- **Stage your own pathspec**, never `git add -A` or a bare `git add notes` — that once swept a
  half-written file of mine into another chat's commit. Commit trailer:
  `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`
- **Verify before `DONE:`** — compose-test + screenshot. See §5.

## 4. Asset facts that will bite you

- **All asset URLs must be absolute** to `https://blacktoprg.netlify.app/...`. The plugin
  **inlines** our CSS into a page on `blacktoprestaurantgroup.com`, so a relative path resolves
  against WordPress and 404s. This is the single most common way to break a section.
- **`website/assets/media/`** holds everything (10MB, down from a 36MB drop: heavy rasters are
  webp). Fonts are **self-hosted** there — no Google Fonts, no WP uploads folder. `netlify.toml`
  sends `Access-Control-Allow-Origin: *` for woff2, which is what makes the cross-origin font
  load work; don't remove it.
- **`svg/icons/*` are the LIGHT-ground variants.** `smiley-fill.svg` renders as a black disc on
  our dark sections; `bolt.svg` is *white* and vanishes on white. For dark grounds use
  `icons/icn-clust-*`. Check the fill before you place an icon.
- **`svg/icons/asterisk.svg` is a badge lockup** (3 paths incl. its blob), not a bare glyph —
  masking with it yields a solid disc. The bare asterisk is `icons/icn-misc-ast-blk.svg`.
- **`bg/base/base-*.webp` is the hero collage**, pre-composed at 8 widths with the spray crown
  already baked in. Don't rebuild it from separate plates — that was an early wrong turn.
- **`assets/media/lines/`** holds Sean's hand-drawn underlines (SPEC-003). Animate them with a
  **clip-path wipe, never `scaleX`** — scaling stretches the taper.
- **`website/mocks/`** holds the Figma exports. It is **gitignored** (88MB) — present on this
  machine only. Full-page PNGs are **@2x**, so the annotation y-ranges below double.

**Section y-boundaries** (at 1x) for slicing comps, decoded from the Figma annotation columns:
home `0/1148/2160/2974/3984/5074`; our-restaurants `0/916/2476`; team `0/916/3496/4028`;

## 5. The harness (`notes/finesser/`)

```bash
node notes/finesser/compose.mjs --stack --serve      # compose all pages, serve on :8787
node notes/finesser/shot.mjs home--stacked           # desktop 1440 + mobile 390, full page
node notes/finesser/shot.mjs home--stacked --fold    # above-the-fold only
node notes/finesser/shot.mjs home--stacked --probe   # dump engine state, no screenshot
node notes/finesser/shot.mjs "https://…/careers/"    # probe/shoot a LIVE url
node notes/finesser/compose.mjs --live               # compose from the CDN, not local files
```

`compose.mjs` reproduces exactly what the plugin assembles. `shot.mjs` drives the system Chrome
over CDP with zero dependencies.

**Why the harness does odd things — each of these was a real bug first:**

- **It forces `.is-in` on every `.reveal`.** IntersectionObserver never fires for off-screen
  sections in a single capture, so a full-page shot would otherwise be mostly blank.
- **It asserts readiness instead of sleeping.** Only `brgw.js` clears `.anim-head{opacity:0}` —
  CSS never does. A shot taken early silently loses every display headline while still looking
  like a valid page. If you see `⚠ … not trustworthy`, **the shot is worthless** — re-run.
- **It forces images eager and awaits decode.** `loading="lazy"` images below the fold
  photograph blank.
- **It pins `.brgw-header` to `position:static`.** `captureBeyondViewport` renders sticky
  against the *expanded* viewport, which ghosts the header down the page. That looked exactly
  like a duplicate-logo bug for a while.
- **It settles GSAP** — entrance timelines jump to their end, scrubbed ones revert to neutral.
  A parallax frozen at max drift photographs as a misalignment that doesn't exist.
- **It reaps orphaned Chromes by pid.** `pkill -f <pattern>` matches its own `sh -c` command
  line and kills itself; nine orphans once piled up and new launches stopped binding a port.
  Never match on a bare "Google Chrome" pattern — that would kill Sean's actual browser.

**Two environment quirks:** the shell cwd drifts back to the worktree between calls — use
absolute paths or lead with `cd /Users/seanmarshall/Documents/GitHub/brg-web`. And if a shot
fails with "Chrome did not expose its debug port", kill leftover `brgw-shot-` processes first.

## 6. Motion

Two layers, deliberately.

**Baseline — CSS (`brgw.css` + `brgw.js`).** Split-line text, fade-ups, the CTA clip wipe,
doodle jitter, `.brgw-pop` (the splash's pop-in), the slider. Font-gated and FOUC-proof;
degrades with no JS. **Leave this as the baseline** — it's why nothing flashes before Blanco
loads.

**Layer — GSAP + ScrollTrigger**, for scroll-*scrubbed* motion only:

| Hook | Effect |
|---|---|
| `data-brgw-img` | mask opens from the bottom while the image counter-scales 2 → 1.2 |
| `data-brgw-parallax="k"` | scrub drift; `k` is strength, **negative reverses** |
| `data-brgw-pin` | pins for its own height, or `data-brgw-pin-end` |

Use **opposite parallax signs** on stacked plates — counter-movement is what reads as depth;
same-sign plates just slide together.

**The host page already loads the whole GSAP 3.13 suite** (14 files from jsdelivr, incl.
ScrollTrigger, ScrollSmoother, SplitText). `startMotion()` therefore **prefers the host's GSAP**
and only falls back to our vendored copy in `assets/vendor/`. Don't undo that — two copies fight
over `window.gsap` and the second load wins, breaking any host tween holding the first
reference. **ScrollSmoother being present is a latent risk**: if it's ever initialised it takes
over scrolling and our ScrollTriggers would need `scrollerProxy` handling.
