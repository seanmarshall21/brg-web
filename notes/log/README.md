# notes/log/ — shared dated entries

**Shared: any chat writes.** One file per entry, named `YYYY-MM-DD-<chat>-<slug>.md`.

Because every entry is its own file, two chats logging on the same day never touch the same
file — which is the whole reason this exists rather than a shared append-only document.

**Add your own; never edit someone else's.**

What goes here: session summaries, incident write-ups, findings that another chat will need
later, anything long enough that pasting it into `notes/roundtable.md` would bury the thread.

What doesn't: your own decisions (those go in `notes/controller.md` / `notes/finesser.md`),
work with a definite owner (`notes/tasks.json`), or a direct ask (`notes/roundtable.md`).
