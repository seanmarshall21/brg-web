Shortcode Index

plugin v2.2.0

Every BRG shortcode + the attributes you can pass. Reflects the live plugin (vc-clients-embed.php v2.2.0). Pages are code fragments on Netlify pulled into WordPress natively — edit a fragment → git push → live in ~60s. The nav is managed in WordPress (Appearance → Menus).

Whole-page shortcodes

[brg_<slug>] page

AttrDefaultDoes
ttl120Server cache in seconds. ttl="0" = always fresh (use on test pages).
chromeonchrome="0" renders the page bare — no shared header/footer.
Per-page aliases from pages.json: [brg_home], [brg_our-restaurants], [brg_team], [brg_community], [brg_careers].

Chrome (shared header + footer)

[brg_nav] chrome

AttrDefaultDoes
ttl120Server cache in seconds.
No layout attributes — content is a WordPress menu. Appearance → Menus → build "BRG — Primary" → Manage Locations → assign it. Styling (white bar, yellow rule, teal marker underline on hover + active page) ships from the repo.

Attribute reference

ttl & ?brg_refresh cache

WhatDoes
ttl="N"attrCache the fetched fragment N seconds (default 120). ttl="0" = never cache — put on test pages so edits show instantly.
?brg_refresh=1URLAdd to any page URL to force every BRG shortcode on it to re-fetch once. Busts the cache after a push without waiting out the ttl.

Slots (per section) content

A section can expose {{token}} slots (heading / sub / cta_label / cta_href / anchor) you override from the shortcode, escaped by type (text/url/html). Mechanism is live; no section declares slots yet — all copy is baked into fragments. When Finn adds slots, you'll pass e.g. [brg_cta-band heading="Apply today" cta_href="/careers/"].

Not yet configurable — Temper has these, BRG doesn't (yet)

  • Nav layout modes — per-side counts, logo-center / compact, a More overflow drawer.
  • A CTA pill (Temper's Tickets) — BRG has none; could add a Contact / Order button.
  • Auto-invert over dark/light sections — code is in brgw-nav.js but gated off (nav is solid white by design).
  • [brg_footer] options — capture/wordmark/layout/band/reg. Not ported.

Want any of these? Say which and I'll add it + update this index.

Naming. [brg_<slug>] = a whole page · [brg_<page>-<section>] = a section · [brg_nav]/[brg_footer] = chrome.

Adding things (no plugin edits). New page → add website/<slug>/embed.html + a line in pages.json, push, drop [brg_<slug>]. New section → add website/sections/<id>/embed.html + a line in sections.json, push, drop [brg_<id>]. New nav item → Appearance → Menus (no code).
